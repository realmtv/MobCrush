Mob Crush v1.0 Alpha — Релиз 🚀

Добро пожаловать в первый стабильный альфа-релиз Mob Crush! Это динамичная аркада в жанре «оборона», где ваша задача — удерживать позицию на шоссе и не дать бесконечному потоку врагов пройти мимо вас.
Что нового в этой версии (v1.0 a):

    🎨 Кастомное меню паузы: Нажатие Escape больше не вызывает стандартное системное окно Windows. Теперь игра показывает стильный интерфейс поверх экрана с кнопками управления.
    ⚔️ Режим спам-атак: Механика ударов полностью переписана. Анимация руки теперь мгновенно сбрасывается при каждом клике, позволяя атаковать так быстро, как вы можете нажимать кнопку мыши.
    📊 Визуализация прогресса: Добавлено отображение текущего уровня игрока (Lvl X) прямо над полоской опыта. Вы сразу видите свой рост.
    🏷️ Ребрендинг: Проект официально переименован из "Tricks" в Mob Crush.

Основные механики:

    Бесконечный геймплей: Враги спавнятся сверху и движутся вниз по дороге.
    Система урона: Атакуйте врагов, пока они находятся в зоне поражения вашей руки, чтобы отбрасывать их назад или уничтожать.
    Набор опыта (XP): За каждого поверженного противника начисляется опыт для повышения уровня.
    Ускорение времени: Специальная кнопка позволяет включить режим x2 для более быстрого прохождения стадий.
